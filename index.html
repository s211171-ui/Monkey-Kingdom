Activate Your Monkey Pocket

Please follow these two steps to complete device activation

1

Enter Activation Code

Find the activation code card in your Monkey Pocket packaging and enter it below to activate your device.

Format: MK-XXXX-XXXX-XXXX (X is letter or digit)

Activation Successful!

Your Monkey Pocket has been successfully activated. Please proceed to step 2 to complete setup.

Activation Failed

Invalid activation code or already used. Please check and try again.

2

Bind IP Address & Real-name Verification

For security reasons, please bind your home IP address and complete Hong Kong ID verification.

Format: 1 letter + 6 digits + 1 check digit in brackets

Binding Successful!

Your IP address has been successfully bound and real-name verification is complete. You can now start using Monkey Pocket!

Binding Failed

Invalid Hong Kong ID number format. Please check and try again.
